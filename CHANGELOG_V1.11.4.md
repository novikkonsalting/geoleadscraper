# v1.11.4 — из завершённого сбора не было выхода, кроме RESET

## Баг

После `IMPORT RAW CSV` панель переходит в состояние «RAW-СБОР ЗАВЕРШЁН». В этом
состоянии кнопки **ЗАГРУЗИТЬ CSV СО СПИСКОМ ЗАПРОСОВ не было вообще**. Список
кнопок был такой:

```
IMPORT RAW CSV — ДОБАВИТЬ ВЫГРУЗКУ EXPORT RAW
EXPORT RAW (4121)
FILTER RAW → FINAL
RESET BATCH — УДАЛИТЬ RAW (4121)
```

То есть загрузить запросы следующего района было нельзя ничем, кроме RESET,
который стирает весь реестр — ровно то, чего делать нельзя и о чём тут же
написано под кнопками. Тупик.

Попытка загрузить `05_kotlovka.csv` через IMPORT RAW давала корректное
сообщение «Загрузите его кнопкой ЗАГРУЗИТЬ CSV СО СПИСКОМ ЗАПРОСОВ» — кнопки,
которой на экране не было.

## Исправлено

В завершённом состоянии первой кнопкой идёт
**ЗАГРУЗИТЬ CSV СО СПИСКОМ ЗАПРОСОВ — СЛЕДУЮЩИЙ РАЙОН**. Реестр она не трогает:
заменяется только очередь запросов, и сразу появляется START RAW BATCH.

Добавлена проверка состава кнопок в каждом состоянии панели: из любого
состояния должен быть путь дальше, отличный от RESET.

## Порядок работы

```
IMPORT RAW CSV                       (вернуть накопленное, если нужно)
ЗАГРУЗИТЬ CSV СО СПИСКОМ ЗАПРОСОВ    05_kotlovka.csv
START RAW BATCH
EXPORT RAW                           (страховка)
ЗАГРУЗИТЬ CSV СО СПИСКОМ ЗАПРОСОВ    07_obruchevskiy.csv
START RAW BATCH
...
FILTER RAW → FINAL                   (один раз в конце)
EXPORT FINAL
```

RESET BATCH — только когда реестр действительно надо выбросить.
