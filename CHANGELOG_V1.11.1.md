# v1.11.1 — районы копятся в одном реестре

## Что было не так

На вопрос «что значит не сбрасывать RAW» выяснилось, что виноват интерфейс.

**Загрузка CSV следующего района обнуляла счётчик в панели.** Хранилище при
этом оставалось нетронутым, но панель показывала «RAW уникальных организаций:
0» — и выглядело это ровно как «всё стёрлось». То же самое делал START RAW
BATCH. Счётчик сбрасывался, потому что состояние BATCH собиралось заново, а
итоги берутся из него, а не из хранилища.

**IMPORT RAW CSV действительно стирал реестр перед импортом.** Собрать два
района обратно в один файл было нельзя.

Вместе это приводило к сбросу данных между районами. Цена видна на ваших
файлах:

```
Коньково           1174 организации
Академический      2373 организации
вместе             2631, а не 3547
```

**916 организаций были собраны дважды** — они попадают в выдачу обоих районов,
и при накоплении второй раз их собирать не нужно.

## Исправлено

* Загрузка CSV с запросами и START RAW BATCH больше не обнуляют счётчик: он
  читается из хранилища. Реестр они и раньше не трогали — теперь это видно.
* **IMPORT RAW CSV добавляет к реестру, а не замещает его.** Дедуп по
  `place_id`, провенанс обеих сторон сохраняется: организация, найденная и в
  Академическом, и в Коньково, получает обе записи и `source_district`
  «Академический | Коньково». Импорт одного и того же файла дважды ничего не
  меняет.
* Под кнопками появилась строка: загрузка следующего CSV реестр не трогает,
  удаляет данные только RESET BATCH.

Проверено объединением ваших двух выгрузок: 2631 организация, 4565 попаданий по
запросам, общий FINAL — 336 строк (242 Академический, 94 Коньково).

## Как теперь работать

1. Поставить v1.11.1.
2. **IMPORT RAW CSV** — вернуть уже собранные районы (можно по одному файлу,
   они сложатся).
3. Загружать `05_kotlovka.csv`, `06_lomonosovskiy.csv` и далее по одному,
   каждый раз **START RAW BATCH**.
4. **RESET BATCH не нажимать** до самого конца.
5. В конце один раз **FILTER RAW → FINAL** и **EXPORT FINAL** — реестр по всем
   районам сразу.

Экспортировать RAW после каждого района всё равно стоит: это страховка на
случай падения браузера.
