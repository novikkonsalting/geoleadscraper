GeoLeadScraper Yandex AUTO/BATCH v1.3.0 FAST+FILTER

Новое в 1.3.0:
- FAST DEDUPE до загрузки карточки: place_id извлекается прямо из URL Яндекс Карт;
- повторный place_id внутри запроса больше не вызывает повторный запрос карточки;
- общий внутренний card cache на весь BATCH: карточка, уже полученная в одном запросе, повторно по сети не загружается в следующих запросах;
- уменьшена безопасная пауза после реально новой сетевой карточки;
- фактическая категория Яндекса проверяется против category из входного CSV;
- нерелевантные по категории результаты не попадают в итоговый BATCH CSV;
- если адрес явно содержит другой район ЮЗАО, такой результат также отсеивается;
- экспорт добавляет category_validation, district_validation, detected_district;
- UI показывает: сетевые карточки, FAST skip, повторное использование cache, отсеянные категории/районы.

ВАЖНО ПО РАЙОНАМ:
Точная проверка координаты по административному полигону района в v1.3.0 еще не включена.
Сейчас районный guard отбрасывает только явный mismatch, когда другой район прямо присутствует в адресных данных.
source_district остается районом поискового запроса, а не доказательством фактической географии.

Рекомендуемый тест перед 264 запросами:
1. RESET BATCH.
2. Запустить тестовый CSV на 6 запросов.
3. Сравнить время первого запроса с v1.2.2.
4. На 2-м и следующих запросах проверить рост счетчика «Из общего кэша».
5. Экспортировать BATCH и проверить category_validation.
