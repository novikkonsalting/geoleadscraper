КАК РАБОТАЕТ v1.4.0 RAW-FIRST

1. Загрузите CSV с запросами.
2. Нажмите START RAW BATCH.
3. Расширение собирает карточки Яндекс Карт без отбрасывания по категории/району.
4. После завершения нажмите EXPORT RAW — это полный страховой реестр.
5. Нажмите FILTER RAW → FINAL, когда хотите выполнить локальную классификацию и геофильтрацию.
6. При успешной фильтрации нажмите EXPORT FINAL.

Важно:
- Если фильтр границ не смог загрузиться или оказался некорректным, RAW не повреждается и остаётся доступен для экспорта.
- Не нажимайте RESET BATCH до экспорта RAW, если сбор был долгим.
- Второй CSV с официальными источниками ФНС/Минюста не предназначен для GeoLeadScraper.
