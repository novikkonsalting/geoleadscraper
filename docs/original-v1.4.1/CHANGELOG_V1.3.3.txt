GeoLeadScraper v1.3.3 GEO-STRICT

Исправления геофильтра:
- новый cache key границ v3: старый geo cache полностью игнорируется;
- обязательный bounding-box guard перед point-in-polygon;
- sanity-check размера и географического положения каждого polygon feature;
- regression self-test перед запуском BATCH;
- контрольная точка у м. Академическая должна попадать в Академический район;
- точки, ошибочно принятые за Академический в v1.3.2, должны быть отвергнуты;
- при попадании точки сразу в несколько районов запись считается неоднозначной и не принимается;
- batch/auto storage переведены на v4, чтобы результаты старого ошибочного геофильтра не переиспользовались;
- UI: v1.3.3 GEO-STRICT / STRICT + SELFTEST.
